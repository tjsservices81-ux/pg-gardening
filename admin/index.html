If the login box does not appear

It is one of two switches in the Netlify dashboard, and both are one-off:

  1. Site configuration → Identity → Enable Identity
  2. Identity → Services → Git Gateway → Enable

If you clicked an invite email and landed on the ordinary website

That is normal and it is now handled — the site forwards you here automatically. If it happened before this fix, open the email again and click the link a second time, or paste the whole address into the bar including the long #invite_token=… part on the end.
